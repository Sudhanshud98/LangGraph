# LangGraph Practice Repository

Hands-on LangGraph learning repository focused on building stateful, agentic, and graph-based LLM workflows using the LangGraph framework.

This repository contains practical implementations and experiments created while learning:
- LangGraph fundamentals
- Stateful AI workflows
- Multi-step reasoning pipelines
- Agent orchestration
- Conditional execution flows
- Human-in-the-loop systems
- Multi-agent architectures
- Memory-driven AI applications

---

## Overview

This repository serves as a practical workspace for exploring graph-based orchestration for LLM applications after learning LangChain fundamentals.

The project focuses on understanding how LangGraph enables:
- Stateful execution
- Directed workflow orchestration
- Cyclical agent loops
- Multi-agent collaboration
- Dynamic routing
- Production-oriented AI pipelines

The repository includes multiple standalone implementations demonstrating different LangGraph concepts and orchestration patterns.

## Installation

### Clone Repository

```bash
git clone git@github.com:Sudhanshud98/LangGraph.git
cd LangGraph
```

### Create Virtual Environment

```bash
python -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
